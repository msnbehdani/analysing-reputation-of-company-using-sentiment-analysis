\# analyzing reputation of company using sentiment analysis



This project analyzes the reputation of a company by applying sentiment analysis on customer reviews. The study uses McDonald's store reviews dataset and applies Natural Language Processing (NLP) techniques to classify sentiments and extract insights about customer perceptions.



This project was developed as part of an MSc in Artificial Intelligence and Data Science.



---



\## Objectives



\- Analyze customer reviews using sentiment analysis

\- Identify key factors influencing brand reputation

\- Apply machine learning models for sentiment classification

\- Interpret model predictions using Explainable AI techniques



---



\## Dataset



The dataset used in this project contains McDonald's store reviews.



Dataset source:

https://www.kaggle.com/datasets/nelgiriyewithana/mcdonalds-store-reviews
